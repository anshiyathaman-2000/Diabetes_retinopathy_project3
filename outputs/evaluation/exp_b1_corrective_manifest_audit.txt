EXECUTIVE SUMMARY
----------------------------------------------------------------------------------------------------
This audit establishes a leak-free, mathematically verified corrective dataset partition for
Exp B1 (ResNet-50 512x512) on IDRiD Disease Grading. The completed original Exp B1 run (which used
leakage_aware_split_manifest.json, N=330 train) included training image IDRiD_118 (Grade 0), which is
cryptographically identical to official test image IDRiD_064 (Grade 3).

To guarantee absolute test-set integrity without altering official clinical ground truths, the
corrective partition removes IDRiD_118 from the training set (N=329 train, N=83 val), while keeping
the official test set (N=103) completely intact with its official Grade 3 label for IDRiD_064.

All 9 mandatory verification checks PASSED. A dedicated configuration has been prepared.
Per the strict stop condition, NO TRAINING WAS INITIATED.

====================================================================================================
Cross-Split Duplicate Identification:
  - Training Image : B. Disease Grading/1. Original Images/a. Training Set/IDRiD_118.jpg
  - Test Image     : B. Disease Grading/1. Original Images/b. Testing Set/IDRiD_064.jpg
  - SHA-256 Hash   : 505330878f4d4186a71b8001570100b82b6b05cb431e81e2c259d8c584314708
  - File Byte Size : 8,639,114 bytes (Both images identical at the binary level)
  - Official Labels:
      * IDRiD_118 (Train): Grade 0 (No Diabetic Retinopathy)
      * IDRiD_064 (Test) : Grade 3 (Severe Non-Proliferative Diabetic Retinopathy)
  - Clinical Conflict: High-grade conflicting annotation in IDRiD official ground truth.
  - Leakage Mechanism: When IDRiD_118 was present in training, the network was exposed during training
                       to the exact fundus image present in the holdout test set. Although the model
                       did not predict Grade 0 during test evaluation (it predicted Grade 2 Moderate DR
                       with 41.5% confidence), the presence of the test image's visual features during
                       gradient optimization constitutes cross-split feature leakage.
